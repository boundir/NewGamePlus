# New Game Plus

This mod carries your setup into every new colony, so you stop redoing the same configuration each time.

[Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=2909126210)

## Features

- **General.** Default gameplay, medical, production and threat response settings, applied to
  every new game and to bills, outfits, factions and colonists that appear while playing.
- **Storyteller.** Pre-selects the storyteller, the difficulty (including every custom difficulty
  setting), commitment mode and the anomaly playstyle on the new-game screen. You can still change
  everything before starting.
- **Policies.** Apparel, food, drug and reading policies carried into every new game. A policy
  that allowed everything stays open to items from mods you install later.
- **Areas.** Allowed area names and colors, recreated (empty) on the starting map.
- **Bills.** Every save captures that colony's workbench bills into a per-colony group (can be
  turned off in the settings). Keep your favorites in a cross-game library and import them back
  from any workbench's Bills tab.

## Requirements

- [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077)
